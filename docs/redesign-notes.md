# ملاحظات التطوير الجاي (مستنية موافقة سيد قبل الرفع)

## اتعمل محليًا (مش مرفوع)
- السحب بين الصفحات اتعكس زي الكتاب العربي: سحب لليمين = الصفحة الجاية، لليسار = اللي قبلها. (site/js/core/flip.js)

## مقترح الـLayout
1. شريط سفلي 4 تابات + زرار (+) في النص: اليوم · المشاريع · (+) · المهام · أنا
   - "أنا" يجمع: تقريري (الميزان)، الفلوس، الأفكار، الأذكار، الإعدادات.
2. هيدر بعنوان كبير بيصغر مع السكرول، فيه اليوم والتاريخ.
3. اليوم = لوحة Widgets:
   - كارت رئيسي: حلقة تقدم اليوم + "الحاجة الجاية".
   - صف صغير أفقي: الصلاة الجاية، الدواء الجاي، الأذكار.
   - كروت المهام متجمعة بالمشروع.
   - الجزء الشخصي (مزاج، تسجيل اليوم) قابل للطي.
4. المشاريع: كارت فيه شريط تقدم (% مهام خلصت) + لون الحالة + أول حرفين من اسم العميل.
   - تفاصيل المشروع بتابات داخلية: نظرة عامة / المهام / المستشار / السجل بدل صفحة طويلة.
5. المهام: فلاتر ثابتة (النهارده / الأسبوع / بعدين / بدون موعد) بدل سكرول طويل.
   - سحب الكارت: خلصت / أجّل لبكرة.
6. نظام تصميم موحد: مسافات 8px، نوعين خط بس، أرقام tabular، علامة صح متحركة + هزة عند الإنجاز، Empty states بجملة وزرار.

## تطوير الميزان → "تقريري"
المشكلة: الصفحة فيها 7 حاجات مختلفة مالهاش ترتيب (أرقام، رسمة، مشاريع، صلاة ودواء، مزاج، أهداف، إنجازات)، وأرقام زي "نسبة الإنجاز" و"سلسلة الأيام" مش مفهومة.

التقسيم المقترح بتابات فوق: الأسبوع / عاداتي / الأهداف / الإنجازات

- الأسبوع:
  - جملة حكم أوتوماتيك بدون AI: "قفلت 14 مهمة (+4 عن اللي فات)، أكتر وقتك راح على الأهرام، و3 مهام مترحّلة."
  - 3 أرقام بس: خلص / متأخر / مترحّل، كل رقم بسهم مقارنة بالأسبوع اللي فات، والضغط عليه يفتح القايمة.
  - وقتك راح فين: شريط واحد ملوّن بنسبة كل مشروع.
  - شريط الأيام (سبت → جمعة): كل يوم خانة فيها عدد المنجز + وش المزاج + 5 نقط للصلاة.
  - انتبه: مهام اترحّلت 3 مرات، مشاريع مافيهاش حركة 7 أيام.
  - زرار: راجع الأسبوع مع المدرب.
- عاداتي: الصلاة في وقتها %، الالتزام بالدواء %، القضاء، خط المزاج والطاقة.
- الأهداف: كروت الأهداف والخطوة الجاية بارزة.
- الإنجازات: Timeline بالشهور + تصدير CV.
- علامة (i) جنب كل رقم بتشرح هو بيتحسب إزاي.

## قرارات مطلوبة من سيد
- اسم الصفحة: "تقريري" ولا يفضل "الميزان"؟
- ترتيب الشريط السفلي المقترح موافق عليه؟
- الصلاة والدواء: تفضل في "اليوم" بس ولا كمان في "عاداتي"؟
